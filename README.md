  <img src="https://raw.githubusercontent.com/DTM-Mods/.github/main/assets/features.jpg" alt="Features" width="100%">
</p>

- Open **ESC > Settings > General** and scroll to **F1 help entries**. Every key hint seen this session is listed there, from the base game and from mods like AutoDrive and Courseplay.
- Set an entry to **Hidden** and it is gone from the F1 box. The key itself still works.
- Your choices are kept for all savegames in `modSettings/FS25_F1Toggle/F1Toggle.xml`. That file also lists every entry seen so far, so you can set `hidden="true"` there too.

### Console commands

| Command | What it does |
| --- | --- |
| `f1tList` | Lists the entries |
| `f1tShowAll` | Shows everything again |

<p align="center">
  <img src="https://raw.githubusercontent.com/DTM-Mods/.github/main/assets/installation.jpg" alt="Installation" width="100%">
</p>

Put `FS25_F1Toggle.zip` in `Documents/My Games/FarmingSimulator2025/mods`.
